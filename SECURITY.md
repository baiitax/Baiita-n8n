# Security policy

## Supported code

Security fixes are accepted for this repository's original preview server, UI, and deployment configuration. The n8n application and its container image are maintained upstream by [n8n](https://github.com/n8n-io/n8n).

## Reporting a vulnerability

Please do not publish credentials, private workflow exports, database backups, encryption keys, or an unpatched vulnerability in a public issue. Use GitHub's [private vulnerability reporting](https://github.com/baiitax/Baiita-n8n/security/advisories/new) when available, or contact the repository maintainers through the private channel configured for this repository.

For vulnerabilities in n8n itself or its official image, follow the [upstream n8n security policy](https://github.com/n8n-io/n8n/blob/master/SECURITY.md).

When reporting, include the affected version/commit, deployment mode, impact, and a minimal reproduction. Redact secrets and personally identifying data.
